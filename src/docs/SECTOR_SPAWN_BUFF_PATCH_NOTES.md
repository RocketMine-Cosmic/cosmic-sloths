# 🚀 Sector Spawn Buff — Patch Notes (Discord-ready)

**Date:** 2026-05-28
**Affects:** Sector runs (not endless / not raids)

---

## 📣 Hey pilots!

We've been listening. A few of you (shoutout Simon, AnubisDominus, ReZuM 🙏) flagged something important: **the stronger you get, the more your score feels stuck.** You spend gold and OMENX to power up, but the screen doesn't fill up any faster, so there's nowhere to put all that extra DPS.

That's not how this game should feel. You should be rewarded for getting stronger.

This patch is a **direct fix for that bottleneck** — focused entirely on sectors (the runs that actually count for the leaderboard).

---

## 🔧 What's changing

### 1. 🌊 The wave can finally keep up with you
The game has a system called **Dynamic Difficulty** that quietly ramps up spawn rate when you're dominating a run. The problem? It was capped too low — top players blew past the ceiling in seconds and then the wave just… stopped scaling.

**Now:** that ceiling is raised significantly. If you're crushing a run, the enemies will keep coming **harder, faster, and in bigger numbers** than before.

### 2. ⚡ More enemies per second is possible
Previously the game capped at roughly **20 spawns per second**. For most players that's plenty — for whales running with a maxed build, that was a hard wall.

**Now:** the cap is doubled to **40 spawns per second**. You'll only ever see this if you're already crushing the wave at max Dynamic Difficulty.

### 3. 🎯 No more dead 30 seconds before the boss
There's an anti-farming rule that quietly slows spawns in the last 30 seconds of a sector run (to stop people hugging the timer). Fair on average runs — **brutal for fast clearers** who'd already wiped the wave and were just waiting around for the boss with nothing to shoot.

**Now:** if you're dominating the run, **that taper is skipped entirely.** You earned the wave by performing — you get to keep killing right up until the boss appears.

### 4. 💥 Burst spawns at peak performance
When you're at full Dynamic Difficulty (truly steamrolling the run), enemies will now spawn **in pairs** from the same tier band. The screen actually fills up. The power fantasy actually feels powerful.

## ❓ FAQ

**Q: Will my old high score still hold up?**
A: Yes — old scores aren't reset or recalculated. This just opens up a new ceiling above your current one.

**Q: I'm not a top player. Will this make the game harder for me?**
A: No. Dynamic Difficulty only ramps UP when you're already dominating with very few hits taken. If you're getting hit, the system actually ramps DOWN (and that floor is unchanged).

**Q: Does this affect endless or raid?**
A: No — this patch is sector-only. Endless and raid scoring works differently.

**Q: I still hit a cap. What now?**
A: Tell us! We're watching the leaderboard closely. If this isn't enough, we have more tools in the bag (mid-sector mini-bosses, elite scaling, score formula tweaks). One step at a time.
