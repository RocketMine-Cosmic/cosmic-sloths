## 📢 POST 2 — New Score Formula

```
⚖️ **NEW SCORE FORMULA — SECTORS RULE**

Sector runs are what reward OMENX. The new formula makes sure sector clears are also what tops the leaderboard.

**What changes:**
🏆 Sector victories are now the **#1 path to top scores** — multiplier scales with depth (Sector 10 victory ≈ 1M score peak)
🎯 Sector clears reward **progression**, not just survival time
💰 Gold no longer counts toward score *at all*
⏱️ Endless mode still works for fun, mastery & farming — but is no longer the leaderboard meta

**The shift:**
```
Old meta:  grind a long endless run for raw score
New meta:  push deeper into sectors, clear them, win
```

If you want OMENX rewards, you want sector wins. The score formula now reflects that. 🚀

Endless remains a great mastery/gold farm — just don't expect it to top the rewards leaderboard anymore.
```

## 📢 POST 3 — Gold Caps Removed

```
🪙 **GOLD CAPS REMOVED**

Sector runs now mint gold freely with no per-run ceiling. Cosmic Sector 10 clears finally pay what they should.

**Goodbye to:**
❌ "GOLD CAPPED" warning mid-run
❌ Hard fragment cap per run
❌ HUD vs server score mismatches

**For endless farming specifically:**
Gold drops naturally taper after 10 minutes to discourage AFK runs:

```
0–10 min:   1.0× (full value)
15 min:     0.83×
25 min:     0.50×
40 min+:    0.25× (floor — never zero)
```

Sector runs are unaffected by this curve — they always pay full value.

Skilled long endless runs still earn. 4-hour AFK farms don't. 🛌❌
```

## 📢 POST 4 — Balance Levers

```
🔧 **BALANCE CHANGES**

We flattened the multiplier stack at the source so removing caps doesn't break the economy.

**What's changing under the hood:**

🌀 **Talents** — stack factor reduced (0.66×). No more 8-stat compounding chains turning every run into a multiplier explosion.

🎴 **NFT perks** — now apply *additively* with talents instead of stacking on top. Still valuable, no longer game-warping.

💀 **Cosmic difficulty** — gold/XP multiplier reduced from 3× → 2×. Still the hardest mode. No longer the gold meta.

**Net effect:** peak multiplier stack drops roughly in half. The faucet slows by ~50%, which is why the new sinks (next post 👇) won't drain you instantly.
```

## 📢 POST 5 — New: Prestige Relics

```
💎 **NEW: PRESTIGE RELICS**

Once a relic hits **Level 5**, you can now **prestige** it.

🌟 5 prestige tiers (PL1 → PL5)
💸 1.5M gold per relic to fully prestige
📈 +5% relic effect per tier
   *(e.g. Midas Core: +50% gold → +75% gold at PL5)*

**Why flat 1.5M for every relic?**
Fairness. No "casual" pricing tiers, no whale-only paths. Everyone climbs the same ladder at their own pace.

✅ Long-term goal for whales
✅ Shiny progression for mid-tier players
✅ Totally ignorable for new players (focus on basics first)

Available **immediately at S6 launch.** No waiting for content drops.
```
